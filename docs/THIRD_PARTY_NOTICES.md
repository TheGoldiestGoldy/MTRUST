# Third-party notices and licensing status

This public snapshot contains project-authored documentation, benchmark harnesses, tests, measurement summaries and static audit metadata. It does not include the original MTR JAR, Fabric or Minecraft binaries, third-party libraries, models, textures, fonts, shaders, resource packs, worlds, fixture seeds or raw runtime logs.

The MTR reference release is identified by its published version and SHA-256 in the audit documents; it is not redistributed here. Upstream source licenses do not automatically establish redistribution rights for nested libraries or assets.

**The GoldRail project has not selected or added a project LICENSE file.** Do not infer an open-source reuse grant for this repository from its public visibility. Before any release or reuse, PM must choose a project license and complete a component-by-component source, dependency and asset notice review. Unresolved licensing is a release blocker.
