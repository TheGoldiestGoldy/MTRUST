## Verified facts vs hypotheses vs missing measurements

**Verified facts:** released JAR hash and official Modrinth SHA-1/size match; 10 Python unit tests pass; short 3/3 rail-count replays pass; 16/16 exact-JAR static probes pass; released queue discards oldest over 256; FileLoader CREATE-only plus delete-on-error path; no committed real frame capture. **Hypotheses:** dropped texture jobs leave generating markers forever, far-car CPU work dominates, instancing improves Iris performance, server TSC is the dominant RAM cause. **Unmeasured:** moving trains, S1-S4 workloads, live Minecraft MSPT, server total memory attribution, GPU vs render-thread cost, shader visual differences, addon linkage, real packets, unknown save fields, any Rust speedup.
